# 💰 Finance Tracker

A terminal-based personal/company finance tracker built with Python. Tracks income and expenses by category, calculates balance and profit margin, and saves data between sessions.

This project was built while learning Python fundamentals, gradually adding more advanced features like exception handling, file persistence, and a login system.

## ✨ Features

- 🔐 Login system (create account once, log in on future runs)
- 🔒 Hidden password input (masked with `*`)
- 💵 Add income and expenses with categories
- 📊 Show current balance
- 📈 Detailed report with category breakdown and percentages
- 💾 Data saved to JSON files — picks up where you left off
- ⚠️ Input validation and error handling (supports decimal amounts)

## 🛠️ Technologies

- Python 3

## 📦 Setup

Before running, install the required package:

```bash
pip install pwinput
pip install apscheduler
```

## 🚀 How to Run

1. Clone the repository:
```bash
git clone https://github.com/salehexe/finance-tracker.git
```

2. Open the project folder

3. Run the program:
```bash
python financetracker.py
```
